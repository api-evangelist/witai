# Wit.ai

> Wit.ai is Meta's natural language processing (NLP) platform for building apps and devices you can talk or text to. It turns text and audio into structured meaning (intents, entities, traits), transcribes speech (speech-to-text / dictation), and synthesizes speech (text-to-speech). The HTTP API is authenticated with a Bearer server access token and versioned by date (current: 20240304). Wit.ai is free to use.

## API

- [Wit.ai HTTP API reference](https://wit.ai/docs/http/latest): base URL https://api.wit.ai — message, speech, dictation, synthesize, voices, converse/event, and app model management (entities, intents, traits, utterances, apps, export/import)
- [Getting started / quickstart](https://wit.ai/docs/quickstart)
- [Recipes](https://wit.ai/docs/recipes): Composer, custom context, run custom code

## Auth

- Bearer server access token in the Authorization header; one token per Wit app (wit.ai/apps → Settings). See authentication/witai-authentication.yml.
